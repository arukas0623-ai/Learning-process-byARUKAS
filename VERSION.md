# Version

Current Version: `0.2.0-alpha`

Status: Personal Stable

Maturity: Framework Alpha

## Implemented

- IRLA learning protocol
- Learner State schema and evidence gate
- Answer-isolated recall contract
- Context budget contract
- Pluggable adapter architecture
- Local Markdown/JSON state model

## Not Implemented

- Database
- Web, desktop or mobile UI
- Cloud synchronization
- Multi-Agent orchestration
- Executable source-import and ability-map provider registry

This version is suitable for controlled personal or small-scale trials. It is
not a production learning platform.

## Next stage

`0.3.0-validation` will validate one real learning cycle over time. It is a
validation milestone, not a feature-expansion milestone.
