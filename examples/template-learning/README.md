# Template Learning Instance

This directory is a blank, public-safe instance template. Copy it into a
private User Space and replace the placeholders with a selected knowledge
source, Ability Map and scheduler configuration.

After copying, remove the `.example` suffix from the runtime files (for example,
`learner.md.example` becomes `learner.md`). Keep the resulting files outside the
public repository or under an ignored `private/` directory.

It intentionally contains no real learner history, answers, logs, personal
paths or evidence. Keep actual state outside the public repository, for
example under a local ignored `private/` directory.

Required starting files:

- `learner.md.example`
- `constraints.md.example`
- `competencies.example.json`
- `context-budget.json.example`
- `items.json.example` (scheduler-owned placeholder)
