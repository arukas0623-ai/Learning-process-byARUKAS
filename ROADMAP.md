# Roadmap

路线图只记录保持 Framework 定位所必需的工作，不承诺平台化扩展。

## Completed

- [x] Core architecture
- [x] IRLA protocol
- [x] Learner State
- [x] Evidence Gate
- [x] Context Budget
- [x] Adapter separation
- [x] Public/private data separation
- [x] Public template learning instance

## Planned

- [ ] Executable Adapter interface
- [ ] State migration mechanism
- [ ] Runtime packaging
- [ ] 真实学习周期验证与结果记录

## Not Planned

- [ ] Web Dashboard
- [ ] Cloud synchronization
- [ ] Database-first architecture
- [ ] Gamification system
- [ ] Multi-Agent orchestration

## Version target

`0.3.0-validation` 不代表增加平台功能，而代表完成一个有明确起止、证据
可审计的真实学习周期验证。
